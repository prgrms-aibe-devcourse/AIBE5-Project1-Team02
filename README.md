# 여백 (Yeobaek) - 여행 계획 사이트

여행의 빈 공간을 채워드리는 감성적이고 미니멀한 여행 계획 플랫폼

## 🎯 구현된 주요 기능

### ✅ 1. 여행 일정 생성 및 관리

- **AI Wizard** (`/ai-wizard`): 6단계 질문형 AI 일정 생성
    - 기간/날짜 선택
    - 동행 유형 (혼자/연인/가족/친구)
    - 테마 선택 (힐링/맛집/문화/액티비티/카페/사진명소)
    - 예산 설정
    - 이동 수단 선택
    - 일정 강도 설정
- **Planner** (`/planner/:id`): 상세 일정 편집
    - 드래그 앤 드롭으로 순서 변경
    - 장소 추가/삭제
    - 시간/비용/소요시간 편집
    - 체크리스트 관리
    - PDF 출력 및 공유 기능

### ✅ 2. 여행지 검색

- **Results** (`/results`): 검색 결과 및 일정 리스트
    - 목적지/날짜/인원/테마/예산 기반 검색
    - 필터링 (예산범위, 일정밀도, 이동량, 운영시간 검증)
    - 정렬 (인기순, 평점순, 가격순, 이동시간순)
    - 최근 검색 기록 저장 (로컬스토리지)

### ✅ 3. AI 추천

- **AI Wizard**: 사용자 취향 기반 완성 일정 추천
- **Home**: 이달의 추천 일정 / 가성비 여행 섹션
- 태그 기반 추천 시스템

### ✅ 4. 사진/동영상 업로드

- **Upload** (`/upload`): 여행 미디어 업로드
    - 이미지/비디오 멀티 업로드
    - 드래그 앤 드롭 지원
    - 설명 추가
    - 일정 연결 기능

### ✅ 5. 여행지별 후기

- **Reviews** (`/reviews`): 여행지 후기 시스템
    - 지역별 필터링
    - 별점 평가 (5점 척도)
    - 사진 첨부
    - 일정 연결
    - 도움됨 기능

### ✅ 6. 로그인 시스템

- **Auth** (`/auth`): 완전한 인증 시스템
    - 이메일/비밀번호 로그인
    - 회원가입
    - 로그인 상태 유지 (체크박스)
    - 아이디 찾기
    - 비밀번호 찾기 (임시 비밀번호 발송)
    - 소셜 로그인 (Google, 카카오)

### ✅ 7. 사이트 정보

- **로고**: 투명 배경의 '여백' 로고
- **사이트명**: 여백 (Yeobaek)
- **태그라인**: "여행의 빈 공간을 채워드립니다"

### ✅ 8. 이달의 추천

- **Home 페이지**:
    - 이달의 추천 일정 섹션 (인기 순위)
    - 가성비 여행 섹션
    - 각 카드에 좋아요 수 표시

### ✅ 9. 커뮤니티 (여행 기록지)

- **Community** (`/community`): 사용자 여행 기록 공유
    - 여행 사진/영상 포함 포스트
    - 좋아요/댓글 기능
    - 일정 복사 기능 (다른 사람 일정 가져오기)
    - 지역별 필터링

### ✅ 10. 플래너 상세 기능

- **지역/장소/시간**: 모든 정보 입력 및 편집 가능
- **할 일 체크리스트**: 여행 준비 사항 관리
- **지��� 루트**: Google Maps API 통합
    - 실시간 경로 표시
    - 마커 및 번호 표시
    - 자동 바운드 조정
- **이동 경로 비용**:
    - 이동 수단별 비용 계산 (차량/대중교통/도보)
    - 이동 시간 및 거리 표시
- **관광지 운영시간**:
    - 각 장소별 운영시간 명시
    - 운영시간 검증 시스템
    - 경고 알림
- **관광지 입장 비용**:
    - 장소별 입장료 상세 표시
    - 무료/유료 명확히 구분
    - 일별/전체 비용 합계

### ✅ 11. 마이페이지

- **MyPage** (`/mypage`): 개인 관리 허브
    - 저장한 일정 관리
    - 업로드한 사진/영상 갤러리
    - 작성한 후기 목록
    - 통계 (일정/업로드/후기 개수)

### ✅ 12. 상세 페이지

- **Plan Detail** (`/plan/:id`): 일정 상세 보기
    - 타임라인 + 지도 시각화
    - Day별 탭 전환
    - 운영시간 검증 결과
    - 비용 상세 내역
    - 저장/공유 기능

    - 트랜지션

## 🗺️ 지도 기능 (Google Maps API)

### 구현된 기능

- 장소 마커 표시 (번호 포함)
- 경로 라인 그리기 (Polyline)
- 자동 중심/줌 조정
- InfoWindow (장소 클릭 시)
- 커스텀 마커 스타일

### 설정 방법

1. Google Cloud Console에서 API 키 발급
2. `/index.html`의 `YOUR_API_KEY`를 실제 API 키로 교체
3. Maps JavaScript API 및 Places API 활성화

## 🚀 사용 기술

- **Frontend**: React 18 + TypeScript
- **Routing**: React Router v6
- **Styling**: Tailwind CSS v4
- **Maps**: Google Maps JavaScript API
- **Icons**: Lucide React
- **Notifications**: Sonner
